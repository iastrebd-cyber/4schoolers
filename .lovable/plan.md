

# Увеличение логотипа в шапке

## Что меняем
В `src/components/site-header.tsx` увеличить логотип "4Schoolers" в верхней навигации, чтобы он стал визуально крупным и заметным (сопоставимым по присутствию с футером и общей композицией страницы).

## Изменения

**Файл:** `src/components/site-header.tsx`

1. Увеличить высоту логотипа с `h-10` до `h-16` на мобильных и `h-20` на десктопе (`h-16 lg:h-20`).
2. Увеличить высоту контейнера хедера, чтобы логотип помещался без обрезки: с `h-18` → `h-24 lg:h-28`.
3. Уменьшить вертикальные паддинги контейнера (`py-4` → `py-3`), чтобы логотип имел больше пространства по высоте без излишнего раздувания всей шапки.

Итог:
```tsx
<div className="mx-auto flex h-24 lg:h-28 max-w-7xl items-center justify-between gap-6 px-6 py-3 lg:px-10">
  <Link to="/" className="flex items-center gap-2.5 group">
    <img src={logo} alt="4Schoolers logo" className="h-16 lg:h-20 w-auto" />
  </Link>
  ...
```

## Технические детали
- Меняем только классы Tailwind на двух элементах (`<div>`-контейнер и `<img>`).
- Никакая другая логика, навигация и мобильное меню не затрагиваются.
- Sticky-поведение и backdrop-blur при скролле сохраняются.
